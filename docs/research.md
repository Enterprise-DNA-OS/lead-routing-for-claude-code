# Target research, 29 October 2026

Chili Piper, lead-routing family, not present in the target registry when selected. Public list-price starting scenario: $15,000 per year for Routing & Scheduling. This is not an observed customer invoice. The vendor displays dollar amounts without a clear currency label in the fetched page, so the public copy preserves its dollar notation.

Scores, each out of five: annual bill 2; data-shaped 5; our buyers pay for it 2; search demand 3; one-session buildable 5; import path 5. Total 22/30. Buyer fit is a hypothesis: the repository search found no named customer purchasing this tool. Search results show pricing and alternative intent but no verified query volume.

Alternatives considered: ReviewStudio creative proofing, 14/30 (2,3,2,2,3,2), with fifty annual Advanced seats at the published rate reaching a five-figure scenario but a weaker fit for a conversational record. Optimizely experimentation, 13/30 (1,2,2,4,1,3), rejected because the runtime testing service is a substantial part of the product and no current public bill was verified. FaceUp whistleblowing, 14/30 (1,4,2,2,3,2), rejected because a five-figure bill was not verified and confidential anonymous intake adds operating scope. These are research scores, not rankings of vendor quality.
